Solmara Spot the Difference is a hand-drawn spot-the-difference game in a single self-contained HTML file: three original scenes — a harbour at sunset, a night market and a garden fountain — each shown as two near-identical canvas pictures side by side with exactly seven hidden differences to circle by mouse or keyboard, with a count-up timer, three hearts, limited hints, WebAudio chimes and a score that rewards fast, careful eyes.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in a desktop browser and press Start the hunt.
